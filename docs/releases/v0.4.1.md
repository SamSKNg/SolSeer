# solseer v0.4.1 — target-biome Auto-Join fix

This patch fixes Auto-Join remaining paused after a desired biome is no longer present.

## What changed

- Only a fresh OCR match for a selected target biome keeps Auto-Join paused.
- Auto-Join resumes when OCR recognizes another biome or the target reading expires.
- Signals first detected during the pause remain eligible while still actionable.
- On release, solseer selects only the strongest waiting signal and clears the rest, preventing repeated server switches on following polls.
- The last recognized biome can remain visible in the current-server card without acting as a permanent Auto-Join veto.

## Updating

1. Stop the old app with **Ctrl+C**.
2. Download **solseer-v0.4.1-windows-x64.zip** and extract it into a new folder.
3. Open the `solseer` folder and double-click **Start solseer.cmd**.

Saved settings and biome feedback remain in the separate local settings folder. This patch passes **171 automated tests**, the production build, native helper compilation, and Windows package verification.
