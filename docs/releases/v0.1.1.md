# solseer v0.1.1 — join the server you actually clicked

First bugfix drop. If you've clicked one server and landed somewhere else, this release skips the website join handoff entirely. That's one less step when you're racing the last few open slots.

## Fixed

- **Join / Rejoin now use direct Roblox app links** with the selected place and server IDs, skipping the website handoff associated with reports of ignored server IDs.
- **Copy server link** uses that same direct-app format. Join-click tracking still works; copying doesn't mark a server as joined.
- Added regression tests for switching servers, rejoining, link encoding, and preserving the selected server through live UI updates.

## Faster polling, same heuristics

- Authenticated polling now targets **one request every 3 seconds**, with a local cap of **20 attempts per rolling minute**.
- Anonymous polling stays at **20.5 seconds / 3 attempts per minute**. Roblox cooldowns and authentication-error backoff still apply.
- Early lead stays **net +2 within 15 seconds at 13–18 players**. Rapid filling stays **net +3 within 10 seconds at 13+ players**. Both require an open slot to notify.
- Freshness and follow-up windows are unchanged. The **two-poll card hold** is still two polls—roughly six seconds at the faster cadence.

## Updating

1. Stop the old copy with **Ctrl+C**.
2. Download **solseer-v0.1.1-windows-x64.zip** and extract the whole ZIP into a new folder.
3. Run **Start solseer.cmd**. No separate Node.js installation needed.

Saved local cookie settings and notification preferences are unchanged. Population and join history start fresh when the backend restarts.

Roblox must be installed and signed in. Allow the browser's **Open Roblox?** prompt when you intend to join. Some chat apps won't make `roblox://` links clickable; recipients can paste the full link into their browser's address bar.

## Still a scrappy side project

Direct links don't bypass full servers or access restrictions. Tests verify the selected IDs and local handoff, not actual in-game arrival. Three-second polling is a local target, not a guaranteed Roblox rate allowance, and not every server is observed on every request.

**115 automated tests pass**, plus the packaged-app HTTP checks. These are population leads, not confirmed rare biomes. No cookies or personal settings are included in the download.
