# solseer v0.5.0 — unified OCR and join observations

This release combines biome and Play recognition into one persistent, in-memory OCR pass and replaces manual join-history labels with automatic biome observations. The existing visual theme is retained.

## Changes

- One combined crop reads biome names and the Play marker, even with Auto-Start off. The helper still waits 500 ms after each scan; actual intervals include processing time.
- Roblox window discovery no longer requires foreground focus. Background capture uses Windows PrintWindow; readable frames depend on Roblox rendering and window state. Keep the selected 1080p/1440p fullscreen layout.
- OCR no longer writes temporary PNG files. Fuzzy matching uses a 70% similarity threshold.
- Auto-Start only clicks Play, after two matching scans and while Roblox is foreground. Camera zoom automation has been removed.
- Stale or unclear OCR readings no longer release a selected target-biome pause. Recognizing another biome releases it. Missing Roblox or unavailable helper states also release the pause.
- Join history records the first qualifying OCR biome after account presence confirms the destination Job ID. A valid configured cookie and visible Job ID are needed for attribution; unresolved attempts remain waiting for OCR.
- Automatic observations save locally in `biome-observations.json`, including biome, match score, raw OCR text, timestamps, and population evidence. Existing manual `biome-feedback.json` data is left untouched. OCR labels are observations, not verified ground truth.

## Updating

1. Stop the old app with Ctrl+C.
2. Download `solseer-v0.5.0-windows-x64.zip` and extract it into a new folder.
3. Open the `solseer` folder and double-click `Start solseer.cmd`.

Settings stay in the separate local settings folder. Session history resets when the backend restarts.
