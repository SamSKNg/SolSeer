# solseer v0.3.0 — faster signals, automatic joins, and biome labels

This release tightens the burst model, keeps useful queue signals visible, and adds an opt-in Windows auto-join path for the moments when reacting quickly matters.

## Auto-join that is explicit and tier-aware

- A master **Auto-join** toggle now sits beside **Signals to watch** on the main radar page.
- Settings has independent choices for **Early leads** and **Rapid filling**, so either tier can be included or excluded.
- Auto-join launches at most one newly detected server per poll and never replays a signal that was already active when the toggle was enabled.
- Windows hands the `roblox://` link to the registered Roblox protocol handler and records the join attempt only after the handoff succeeds.
- Full Rapid signals remain actionable because Roblox can place the attempt in a moving queue. Full Early signals remain informational.

Auto-join is off by default. Roblox must be installed and signed in, and solseer cannot verify whether Roblox ultimately admits the account to the server.

## One 15.5-second burst window

- **Early lead:** net **+2 within 15.5 seconds**, at 13–18 players with an open slot.
- **Rapid filling:** net **+3 or more within 15.5 seconds**, at 13+ players, including a burst that reaches 20/20.
- Promoted Early signals now retain the qualifying Rapid evidence, so the badge and supporting subtext stay in sync.
- Retained Rapid signals use **Holding · rapid burst**, while full signals show a clear **Full** indicator.

## Better retention and stale handling

- A detected burst remains visible while more than half of its original gain is still present.
- Once at least half the burst gain has left, the retained signal is removed immediately.
- Servers not actually observed for more than 20 seconds are treated as **Falling off · stale** and removed from signals, while their last reading can remain briefly in the live list for context.

## Labels for future biome analysis

- Join history now lets users mark an attempt as **Rare biome**, **Not rare**, or **Unmarked**.
- Each label saves the join-time signal fields and up to 120 recent public population observations in `%LOCALAPPDATA%\solseer\biome-feedback.json`.
- Changing a label replaces the saved example; choosing Unmarked removes it. Cookies and Roblox account identity are not included.

## Updating

1. Stop the old app with **Ctrl+C**.
2. Download **solseer-v0.3.0-windows-x64.zip** and extract the entire ZIP into a new folder.
3. Open the `solseer` folder and double-click **Start solseer.cmd**.

Restarting the backend is required to load the new auto-join dispatcher. Saved settings and biome feedback remain in the local settings folder. The release passes **159 automated tests**, plus the production build and Windows package checks. Polling tests use synthetic responses, not live authenticated Roblox traffic.
